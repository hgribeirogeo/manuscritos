⎇ GitHub Gist — Sincronização ativo

Salva automaticamente em um Gist privado do GitHub. O token PAT não expira — configure uma vez, funciona para sempre.

Obtenha em github.com/settings/tokens → "Generate new token (classic)" → marque gist → sem data de expiração.
Escaneie o QR code com a câmera do celular (ou abra o link nele) uma única vez. O dispositivo fica configurado e carrega os dados do Gist.
⚠ Este link contém seu token de acesso — trate como senha. Não compartilhe em grupos nem publique.

📲 Instalar como aplicativo

Instala o LabResearch na tela inicial (Android) ou como app no computador — abre em tela cheia e funciona mesmo sem internet (dados locais, enviados ao Gist quando a conexão voltar).

Se o botão não aparecer: no Chrome do Android, menu ⋮ → Instalar app (ou "Adicionar à tela inicial").
